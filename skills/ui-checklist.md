## 常見問題模式

### [P001] CSS 變數名稱不一致
- **症狀**：樣式套用失敗、主題切換無效
- **解法**：統一使用 jet-color-themes.css 定義的變數

### [P002] Master 樣式覆蓋子頁面
- **症狀**：子頁面 CSS 被覆蓋
- **解法**：調整載入順序，利用子頁面後載入的特性
