## 本地化與語言規範 (Localization Standards)

### 語言使用規則

- **預設中文**: 與使用者對話時，所有中文內容**必須使用繁體中文（Traditional Chinese）**，除非使用者明確要求簡體中文
- **專業術語**: 程式碼、變數名稱、註解保持英文，但說明文件可使用繁體中文
- **混合使用**: 技術文件中，專有名詞（如 API、database）保持英文，說明使用繁體中文

### 地區特定術語

**資料表術語（台灣標準）**：
- **Row** = **列（lié）** - 指資料表的橫向記錄
- **Column** = **欄（lán）** - 指資料表的直向欄位
- **Field** = **欄位** - 資料表中的一個欄
- **Record** = **記錄** 或 **資料列** - 資料表中的一列資料

**其他常用術語**：
- **Table** = **資料表** 或 **表格**
- **Database** = **資料庫**
- **Query** = **查詢**
- **Form** = **表單**
- **Report** = **報表**

### 日期與時間格式

- **日期格式**: YYYY-MM-DD（ISO 8601 標準）
- **時間格式**: HH:mm（24 小時制）
- **時區**: 台灣時區 UTC+8（Asia/Taipei）
- **回應結尾**: 每次回答結尾必須加上當天的日期與時間標籤，格式為 `[YYYY-MM-DD HH:mm]`

### 文件命名慣例

- **程式碼檔案**: 使用英文，遵循專案既有命名規範
- **文件檔案**: 可使用繁體中文或英文，視文件性質決定
- **註解與說明**: 繁體中文，提升可讀性

### 溝通準則

- **清晰明確**: 使用台灣地區慣用的專業術語
- **避免歧義**: Row/Column 必須翻譯為「列」/「欄」，不使用其他譯法
- **尊重在地**: 理解並遵循台灣地區的技術用語習慣
