# QA Agent 規範

> 負責：代碼審查、測試撰寫、品質檢查、安全性審查
> 分支前綴：`test/`

---

## 職責範圍

- 代碼審查（Code Review）
- 測試案例設計與撰寫
- 安全性檢查（SQL Injection、XSS 等）
- 效能評估
- 架構一致性檢查
- 文件完整性確認

---

## 代碼審查清單

### 財務系統核心檢查（最重要）

- [ ] **計算邏輯位置正確**
  - 計算在值變更事件中執行，不在 Save 時
  - Sync 函數只讀取 UI，不做計算
  - 用戶手動修改的值不被覆蓋

- [ ] **資料一致性**
  - 顯示的數字與儲存的數字相同
  - PostBack 後數值不被重算
  - 四捨五入邏輯一致

### ASP.NET Web Forms 檢查

- [ ] **控制項宣告完整**
  - 新控制項有對應的 designer.vb 宣告
  - 控制項 ID 命名有意義且一致

- [ ] **事件處理正確**
  - 使用 `Handles` 關鍵字
  - `IsPostBack` 邏輯正確
  - ViewState/Session 使用恰當

- [ ] **UpdatePanel 設定**
  - Triggers 正確註冊
  - 不必要的 PostBack 已避免

### 資料庫操作檢查

- [ ] **SQL Injection 防護**
  - 使用參數化查詢
  - 無字串拼接 SQL

- [ ] **資源管理**
  - Connection 使用 `Using` 區塊
  - Reader/Command 正確關閉
  - Transaction 正確處理（Commit/Rollback）

- [ ] **效能考量**
  - 無 N+1 查詢問題
  - 適當使用索引欄位
  - 大量資料有分頁處理

### SAP B1 整合檢查

- [ ] **COM 物件管理**
  - 所有 COM 物件使用後釋放
  - 使用 `Marshal.ReleaseComObject`
  - 物件設為 Nothing

- [ ] **錯誤處理**
  - 檢查 `GetLastErrorCode()`
  - 錯誤訊息有記錄
  - 使用者收到友善提示

### 安全性檢查

- [ ] **輸入驗證**
  - 前端有基本驗證
  - 後端有完整驗證
  - 檔案上傳有類型/大小限制

- [ ] **XSS 防護**
  - 輸出有編碼處理
  - 使用 `HtmlEncode` / `UrlEncode`

- [ ] **權限檢查**
  - 敏感操作有權限驗證
  - Session 檢查完整

## UI/UX 審查清單

- [ ] **對比度**
  - 文字與背景有足夠對比
  - 深色背景配淺色文字
  - 淺色背景配深色文字

- [ ] **元件比例**
  - 按鈕大小與區塊協調
  - 表格內按鈕使用 `.btn-grid`
  - 間距合理

- [ ] **色彩一致性**
  - 使用 CSS 變數
  - 無硬編碼顏色值
  - 連結顏色為低飽和色

- [ ] **響應式設計**
  - 不同螢幕尺寸顯示正確
  - 表格/表單不溢出

## 問題嚴重程度分類

| 等級 | 描述 | 處理方式 |
|------|------|----------|
| **Critical** | 資料錯誤、安全漏洞、系統崩潰 | 必須立即修復 |
| **Major** | 功能異常、效能問題 | 上線前必須修復 |
| **Minor** | UI 瑕疵、程式碼風格 | 建議修復 |
| **Info** | 優化建議、技術債 | 記錄追蹤 |

## 測試案例設計

### 測試類型

1. **功能測試**
   - 正常流程
   - 邊界條件
   - 異常處理

2. **計算測試**（財務系統重點）
   - 稅額計算正確性
   - 四捨五入行為
   - 用戶修改值保留

3. **整合測試**
   - 與 SAP B1 的資料同步
   - 跨模組資料流

### 測試案例模板

```markdown
## TC-[編號] [測試名稱]

**前置條件**：
- [條件 1]
- [條件 2]

**測試步驟**：
1. [步驟 1]
2. [步驟 2]
3. [步驟 3]

**預期結果**：
- [結果 1]
- [結果 2]

**實際結果**：[待填]
**狀態**：待測試 / 通過 / 失敗
```

## 協作注意事項

- 業務邏輯與計算規則

- 響應式斷點
- 無障礙設計考量

### 回饋給其他 Agent

- 發現的問題與建議
- 需要補充的測試資料
- 技術債記錄
