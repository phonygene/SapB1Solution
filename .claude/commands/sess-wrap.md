# Session Wrap - 階段性存檔（繼續工作）

階段性存檔，但**不結束對話**。

## 參數

- 無參數：正常模式，記錄所有工作內容
- `-s` 或 `--selective`：選擇性記錄模式

## 執行步驟

### 正常模式

1. **總結本階段的工作成果**

2. **更新專案狀態**
   - `.claude/shared/project-status.md`
   - `.claude/shared/active-tasks.json`

3. **記錄到 Work Logs**（如有完成的任務）
   - 路徑：`work-logs/daily/YYYY-MM/YYYY-MM-DD.md`
   - 追加到當日紀錄

4. **向使用者提供彙整報告**
   - 已完成項目
   - 進行中項目
   - 下一步計畫

5. **繼續工作**，不結束對話

### 選擇性記錄模式（`-s`）

1. 列出本階段的所有工作項目
2. 使用 AskUserQuestion 讓使用者選擇排除項目
3. 只記錄保留的內容
4. 其餘同正常模式

## 彙整報告格式

```markdown
# Session Wrap - HH:MM

## 已完成
- [x] 任務 A（簡述）
- [x] 任務 B（簡述）

## 進行中
- [ ] 任務 C（進度 X%）

## 下一步
1. ...
2. ...

---
繼續工作中...
```

## 使用時機

- 長時間工作中途保存進度
- 切換到其他任務前記錄當前狀態
- 避免意外中斷導致進度遺失
