# Reflect - 定期反思機制

整合問題模式識別與學習建議彙整，產出階段性反思報告。

## 參數

- 無參數：反思最近 7 天
- `-w` 或 `--week`：本週反思
- `-m` 或 `--month`：本月反思
- `-a` 或 `--all`：全部反思（謹慎使用，Token 消耗大）

## 執行步驟

### 1. 讀取工作紀錄

讀取指定範圍內的 `work-logs/daily/YYYY-MM/YYYY-MM-DD.md`

### 2. 問題模式分析

- 識別重複出現的問題
- 統計問題類型分布
- 找出失敗/部分完成的案例
- 更新全域問題模式庫：`C:\Projects\claude-config\insights\patterns.md`

### 3. 學習建議彙整

- 收集各日誌中的「學習建議」區塊
- 歸納共同主題
- 識別用戶的：
  1. 明顯錯誤
  2. 應考量卻忽略的盲點
  3. 思維架構落後於最新觀念的地方
  4. 其它風險

### 4. 搜尋最新資訊

針對彙整出的主題，使用 WebSearch 搜尋：
- 相關領域的最新最佳實踐
- 已被普遍驗證的新觀念
- 可能影響現有做法的技術更新

### 5. 產出反思報告

輸出至 `work-logs/insights/reflect-YYYY-MM-DD.md`

## 報告格式

```markdown
# 反思報告 - YYYY-MM-DD

## 統計摘要
- 分析範圍：YYYY-MM-DD ~ YYYY-MM-DD
- 任務總數：N
- 成功：N | 部分完成：N | 失敗：N

## 問題模式

| 模式 | 出現次數 | 相關任務 | 建議對策 |
|------|----------|----------|----------|
| ... | ... | ... | ... |

## 學習建議彙整

### 主題一：[主題名稱]
- **觀察**：期間內的相關建議摘要
- **最新資訊**：網路搜尋結果
- **建議行動**：具體可執行的改進步驟

### 主題二：...

## Skills 更新建議

- [ ] `skills/xxx.md`：新增/修改 XXX
- [ ] 全域 patterns.md：新增 [P00X] 模式

## 待辦事項

同步更新至 `work-logs/TODO.md`：
- [ ] ...

## 用戶決策區

> 以下項目請用戶決定是否採納：

| 項目 | 建議 | 採納？ |
|------|------|--------|
| ... | ... | [ ] |
```

## 使用時機

- 每週固定執行一次（建議週五或週一）
- 感覺最近頻繁遇到類似問題
- 完成一個階段性目標後
- 用戶主動要求檢視學習進度
