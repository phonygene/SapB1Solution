# Session Check - 查看進度報告

查看當前專案進度，**不寫入任何檔案**。

## 執行步驟

1. **讀取專案狀態**
   - `.claude/shared/project-status.md`
   - `.claude/shared/active-tasks.json`

2. **讀取最近工作紀錄**
   - `work-logs/daily/` 最近的紀錄

3. **向使用者報告**
   - 最後更新時間
   - 專案整體狀態
   - 各 Agent 狀態
   - 進行中任務
   - 阻塞項目
   - 下一步建議

## 報告格式

```markdown
# 專案進度報告

## 狀態
- 最後更新：YYYY-MM-DD HH:MM
- 當前版本：vX.Y.Z
- 分支：{branch}

## Agent 狀態
| Agent | 狀態 | 當前任務 |
|-------|------|---------|
| Manager | 🟢/⚪ | ... |
| Backend | 🟢/⚪ | ... |
| UI-UX | 🟢/⚪ | ... |

## 任務概覽
- 進行中：N
- 待處理：N
- 已完成（今日）：N
- 阻塞：N

## 進行中任務
| ID | 任務 | Agent | 進度 |
|----|------|-------|------|
| ... | ... | ... | ... |

## 阻塞項目
- {task-id}: {原因}

## 下一步建議
1. ...
2. ...
```

## 注意事項

- 本指令**只讀取**，不寫入任何檔案
- 用於快速了解專案狀態
- 不影響工作流程
