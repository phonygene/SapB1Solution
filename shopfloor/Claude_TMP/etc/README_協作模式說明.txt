  Claude 協作模式說明 - 檔案輸出方式

更新時間：2025-10-29 03:20

一、目錄結構
---------------------------------------------------------------------
shopfloor/Claude_TMP/
├── SqlQuery/       - SQL 腳本（建表、查詢、修改）
├── dNet/           - VB.NET 完整檔案（.vb, .aspx, .aspx.vb）
└── etc/            - 其他檔案（JSON, TXT 說明文件）

二、檔案命名規範
---------------------------------------------------------------------
1. SQL 腳本：[編號]_[用途]_[物件名稱].sql
   範例：01_CreateTable_user_vendor_taxid.sql

2. VB.NET 完整檔案：直接使用類別名稱.vb 或頁面名稱.aspx
   範例：UserVendorTaxId.vb, ExpenseClaimForm.aspx

3. 部分代碼 TXT：[目標檔案]_[用途].txt
   範例：CommUtil_AddMethods.txt

4. JSON 配置檔：[物件名稱]Config.json
   範例：ExpenseClaimTransactionConfig.json

三、部分代碼 TXT 檔案格式
---------------------------------------------------------------------
每個 TXT 檔案開頭包含：

1. 檔案說明區塊
   - 用途說明
   - 目標位置（應該加入到哪個檔案的哪個位置）
   - 使用方式

2. 需要檢查的點
   - 需要修改的變數名稱
   - 需要調整的參數
   - 相依性檢查

3. 完整代碼
   - 可直接複製貼上的程式碼

四、使用流程
---------------------------------------------------------------------
1. Claude 產生檔案到對應目錄
2. 使用者在 VS Code/Visual Studio 開啟檔案
3. 根據檔案開頭的說明進行操作：
   - SQL 腳本：在 SSMS 執行
   - 完整檔案：加入專案
   - 部分代碼：複製到目標位置

4. 使用者回報結果或問題
5. Claude 根據回報繼續產生下一個檔案

五、溝通方式調整
---------------------------------------------------------------------
Claude 不再在對話中貼大段程式碼，改為：

1. 簡要說明本次產生的檔案
2. 列出檔案清單
3. 說明使用順序
4. 等待使用者回報執行結果

使用者回報時只需簡短回覆：
- "執行成功" / "建表完成"
- "檔案已加入專案"
- "報錯：[錯誤訊息]"
- "需要調整：[具體需求]"

六、優點
---------------------------------------------------------------------
1. 節省 Token（不在對話中顯示大量代碼）
2. 方便使用者直接使用（複製貼上）
3. 保留完整歷史（所有產出都有檔案記錄）
4. 易於版本控制（可 git add 這些檔案）
5. 減少對話視覺疲勞
