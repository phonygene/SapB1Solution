二、協作模式理解確認
---------------------------------------------------------------------
我已確認以下規則：

1. 檔案輸出位置
   - 所有產出必須先輸出到 `shopfloor/Claude_TMP/` 目錄
   - SQL 腳本放 `SqlQuery/`
   - VB.NET 檔案放 `dNet/`
   - 其他說明檔放 `etc/`

2. 命名規範
   - SQL: `[編號]_[用途]_[物件名稱].sql`
   - VB.NET: 類別或頁面名稱 (例如 `UserVendorTaxId.vb`)
   - TXT: `[目標檔案]_[用途].txt`

3. 內容規範
   - 檔案必須包含完整 Header 說明 (如本檔案所示)
   - 程式碼片段不直接貼在對話中
   - 遵守 SQL 保留字檢查 (例如避免使用 User, Order, Date 等作為欄位名)
