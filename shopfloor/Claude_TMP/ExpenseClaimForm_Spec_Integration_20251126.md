## 1. 核心架構修正

本表單為 **「費用申請單」**，其最終目的為在 SAP B1 產生一張 **AP 發票 (OPCH/PCH1)**，並連動 **MDR 營業稅申報資料**。

### 1.1 單據結構

* **表頭 (Header)**：對應 SAP AP 發票表頭 (OPCH)。單一供應商。
* **頁籤 1：費用明細 (Expense Lines)**：對應 SAP AP 發票明細 (PCH1)。每一列為一項費用或商品。
* **頁籤 2：MDR 發票明細 (MDR Invoice Details)**：**[先前誤刪，在此還原]**。對應營業稅外掛所需的中介資料。每一列為一張獨立的實體發票憑證。

### 1.2 資料流向

1. **使用者建立**：在平台填寫表頭、費用明細、MDR 明細。
2. **簽核流程**：儲存 (Draft) -> 匯出 PDF -> 外部系統簽核 -> 取得 PID -> 回填平台。
3. **財會審核**：依據 PID 審核單據 -> 放行 (Approved)。
4. **寫入 SAP**：
   * 呼叫 API 建立 SAP AP 發票 (OPCH/PCH1)。
   * 取得 SAP 新增的 `DocEntry` 與 `DocNum`。
   * 將 MDR 資料寫入中介 Table (`jMGUIAP`, `jMGUIAPDetail`)。
   * (預留) 觸發外部程式將 MDR 資料寫入 SAP 外掛 Table。

## 3. 頁籤規格 (Tabs)

### 3.1 頁籤 1：費用明細 (Expense Claim Lines)

**用途**：產生 SAP AP 發票的內容。
**資料表**：`jPCH1`
**操作**：Grid 可新增/刪除/編輯。

| 欄位                | 說明   | 邏輯                                               |
|:----------------- |:---- |:------------------------------------------------ |
| **LineNum**       | 列號   |                                                  |
| **ExpCategory**   | 費用類別 | 下拉選單 (來源：`expense_category`)。選擇後自動帶出 `AcctCode`。 |
| **Dscription**    | 說明   | 使用者自由輸入。                                         |
| **AcctCode**      | 會計科目 | 唯讀 (由 `ExpCategory` 帶出)。                         |
| **LineTotal**     | 未稅金額 | **編輯此欄** -> 自動反算 `VatSum`, `PriceAfterVat`。      |
| **VatGroup**      | 稅別   | 下拉選單 (來源：SAP `OVTG`)。                            |
| **VatSum**        | 稅額   | 自動計算。                                            |
| **PriceAfterVat** | 含稅金額 | **編輯此欄** -> 自動反算 `LineTotal`, `VatSum`。          |
| **CostingCode**   | 成本中心 | 下拉選單 (OcrCode)。                                  |
| **CostingCode2**  | 部門   | 下拉選單 (OcrCode2)。                                 |
| **Attachment**    | 附件   | 路徑。                                              |

*(隱藏/後端欄位：ItemCode, Quantity=1, Price=LineTotal, Currency)*

## 4. UI/UX 互動規範

### 4.1 搜尋控制項 (Search Button Combo)

* **UI**：[文字框] [放大鏡按鈕]
* **行為**：
  1. 輸入文字後點擊按鈕 (或 Enter)。
  2. **彈出 Modal 視窗** 顯示搜尋結果 Grid。
  3. **絕對禁止** 使用 `SELECT TOP 1` 自動填入，必須讓使用者從清單中選擇 (即使只有一筆)。
  4. 預設使用 **模糊比對 (LIKE %Keyword%)**。
  5. 選擇後關閉視窗，回填代碼與名稱。

### 4.2 驗證機制

* **時機**：`OnBlur` (離開欄位時) 及 `btnSubmit` (送出時)。
* **顯示**：錯誤訊息顯示於該欄位下方或後方 (紅色文字)。
* **阻擋**：若有驗證錯誤，禁止執行儲存或送出動作。
