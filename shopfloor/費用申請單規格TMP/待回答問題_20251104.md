## 問題 1: 檔案上傳的檔名檢查機制 (明細欄位 #10)

**背景**: 您提到「為了防止使用者上傳錯誤檔名造成錯誤,我需要在此限制上傳檔案的檔名格式」

**方案 A: 自動重新命名(推薦)**
- 格式: `{jID}_{LineNum}_{時間戳記}.{副檔名}`
- 範例: `12345_1_20251104223000.pdf`
- 優點: 完全避免檔名問題,易於追蹤
- 缺點: 使用者看不到原始檔名

**方案 B: 檔名清理 + 限制**
- 保留原始檔名,但清理特殊字元
- 移除: `\ / : * ? " < > | ' ; & % $ #`
- 限制長度: 最多 50 字元
- 範例: `發票_20251104.pdf` → `發票_20251104.pdf` (允許中文)
- 優點: 保留原始檔名語意
- 缺點: 可能有同名檔案衝突

**方案 C: 混合方案(平衡)**
- 格式: `{原始檔名(清理過)}_{時間戳記}.{副檔名}`
- 範例: `發票_20251104223000.pdf`
- 優點: 既保留語意又避免衝突
- 缺點: 檔名較長

**您的回答**:
[請在此填寫: A / B / C / 或其他方案]
請使用C方案。
