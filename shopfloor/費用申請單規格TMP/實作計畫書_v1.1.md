## 規格概述

### 核心變更

1. **介面重構**：從 MDR 發票明細單 → SAP B1 標準 AP Invoice 格式
2. **雙頁籤設計**：「費用申請單」頁籤 + 「營業稅發票明細」頁籤
3. **服務類型明細**：改用費用類別 + 費用說明，不使用項目號碼
4. **錯誤驗證**：實作即時欄位驗證與錯誤訊息顯示機制
5. **查詢子視窗**：實作可重用的查詢選擇視窗元件
6. **三層驗證**：SQL Injection 防護 → 資料型別/長度檢查 → 業務邏輯驗證

### 階段劃分

- **Phase 1（本次）**：介面調整 + 錯誤訊息欄位 + 資料型別/長度檢查
- **Phase 2（後續）**：查詢子視窗物件實作
- **Phase 3（後續）**：業務邏輯驗證（發票號碼格式、供應商存在性等）

#### 文件幣別邏輯

1. 查詢業務夥伴幣別：`SELECT Currency FROM OCRD WHERE CardCode = @CardCode`
2. 如果幣別 ≠ `**`（所有幣別）：
   - 下拉選單固定單選項且不可選擇或編輯
   - 直接使用業務夥伴幣別
3. 如果幣別 = `**`：
   - 從 SAP OCRN 表取得幣別列表放入下拉選單
   - 讓使用者選取
4. 當變更業務夥伴時，刷新此欄位

#### 文件匯率邏輯

1. **位置**：放在表頭左側，緊鄰文件幣別右側
2. **自動取得匯率**：
   
   ```sql
   SELECT Rate FROM ORTT
   WHERE Currency = @DocCur
   AND RateDate = @DocDate
   ```
3. **本幣處理**：
   - 若幣別為本幣，禁止編輯匯率，強制值為 `1.0`
4. **外幣處理**：
   - 若幣別為外幣且查不到匯率，留空
   - 觸發驗證錯誤（離開欄位時 or 點擊新增/更新時）：
     - 錯誤訊息：「外幣匯率不得為空」
     - 禁止新增或更新
5. **可編輯性**：
   - 自動帶入預設值
   - 文件未結時，使用者可手動編輯

#### 資料連結（檔案上傳）

**儲存路徑**：


**檔名處理方式**（方案 C：混合方案）：

- 格式：`{原始檔名(清理過)}_{時間戳記}.{副檔名}`
- 範例：`發票_20251104230000.pdf`

**檔名清理規則**：

1. 移除特殊字元：`\ / : * ? " < > | ' ; & % $ #`
2. 空白轉換為底線 `_`
3. 保留中文字元
4. 限制檔名長度：最多 50 字元（不含時間戳記）
5. 時間戳記格式：`yyyyMMddHHmmss`

**實作邏輯**：

```vb
Function CleanFileName(originalFileName As String) As String
    ' 移除副檔名
    Dim nameWithoutExt = Path.GetFileNameWithoutExtension(originalFileName)
    Dim ext = Path.GetExtension(originalFileName)

    ' 移除特殊字元
    Dim cleanName = Regex.Replace(nameWithoutExt, "[\\/:*?""<>|';&%$#]", "")

    ' 空白轉底線
    cleanName = cleanName.Replace(" ", "_")

    ' 限制長度
    If cleanName.Length > 50 Then
        cleanName = cleanName.Substring(0, 50)
    End If

    ' 加上時間戳記
    Dim timestamp = DateTime.Now.ToString("yyyyMMddHHmmss")
    Return $"{cleanName}_{timestamp}{ext}"
End Function
```

**自動建立目錄**：

- 若 `{使用者帳號}` 目錄不存在，自動建立

```
IF SUM(MDR明細.U_HWBAS + U_HWSTE) ≠ AP發票.DocTotal THEN
```

## 錯誤驗證機制

### 三層驗證架構

```
使用者輸入
    ↓
【第一層：SQL Injection 防護】
    ├─ 檢查特殊字元：'; --, /*, xp_, sp_
    ├─ 檢查 SQL 關鍵字：SELECT, INSERT, UPDATE, DELETE, DROP, EXEC
    ├─ 使用參數化查詢
    ↓
【第二層：資料型別與長度檢查】← 本次實作
    ├─ 檢查資料型別（string, int, decimal, date）
    ├─ 檢查字串長度（是否超過 MaxLength）
    ├─ 檢查數值範圍
    ├─ 檢查日期格式
    ↓
【第三層：業務邏輯驗證】← 後續實作
    ├─ 供應商代碼存在性檢查
    ├─ 發票號碼格式檢查
    ├─ 必填欄位檢查
    ├─ 欄位間關聯檢查
```

### 儲存按鈕控制

**規則**：當頁面有任何錯誤訊息顯示時，不允許使用者執行新增或更新表單。

**實作方式**：

```vb
Private Function HasAnyErrors() As Boolean
    ' 檢查所有表頭/表尾錯誤訊息
    If errCardCode.Style("display") <> "none" Then Return True
    If errCardName.Style("display") <> "none" Then Return True
    ' ... 其他欄位

    ' 檢查明細錯誤訊息
    If divDetailError.Style("display") <> "none" Then Return True

    Return False
End Function

Protected Sub btnSave_Click(sender As Object, e As EventArgs)
    If HasAnyErrors() Then
        ShowMessage("請先修正所有錯誤後再儲存")
        Return
    End If

    ' 繼續儲存邏輯...
End Sub
```
