# 問題模式庫

> 記錄識別出的常見問題模式，避免重複犯錯

## [P001] CSS 變數名稱不一致
- **症狀**：樣式套用失敗、主題切換無效
- **原因**：不同檔案使用不同的變數命名慣例
- **解法**：統一使用 jet-color-themes.css 定義的變數名稱
- **首次出現**：2026-01-02
- **出現次數**：1
- **相關任務**：2026-01-02-001

## [P002] Master 樣式覆蓋子頁面
- **症狀**：子頁面的 CSS 被 Master 的樣式覆蓋
- **原因**：CSS 載入順序錯誤（Master 樣式在 ContentPlaceHolder 之後）
- **解法**：調整載入順序，Master 樣式先載入
- **首次出現**：2026-01-02
- **出現次數**：1

## [P003] ADO.NET DateTime 型別推斷錯誤
- **症狀**：SqlDateTime overflow 錯誤（必須在 1/1/1753 ~ 12/31/9999 之間）
- **原因**：`AddWithValue` 將 DateTime 推斷為 SqlDbType.DateTime（範圍 1753-9999），而非 DateTime2
- **解法**：明確使用 `cmd.Parameters.Add("@param", SqlDbType.Date).Value = dateValue`
- **首次出現**：2026-01-13
- **出現次數**：1
- **相關任務**：2026-01-13 SqlDateTime 溢位修復

## [P004] ViewState 暫存資料遺失
- **症狀**：PostBack 後用戶上傳的資料消失
- **原因**：ViewState 在頁面生命週期結束後不會自動持久化到資料庫
- **解法**：需持久化的資料（如附件）應寫入資料庫，ViewState 僅用於頁面狀態
- **首次出現**：2026-01-13
- **出現次數**：1
- **相關任務**：2026-01-13 附件儲存問題修復

## [P005] 按鈕可見性未正確設定
- **症狀**：開啟已儲存文件時，某些按鈕不顯示
- **原因**：LoadDocument 時未設定按鈕的 Visible 屬性
- **解法**：LoadDocument 時一併設定所有相關按鈕的 Visible 狀態
- **首次出現**：2026-01-12
- **出現次數**：1
- **相關任務**：2026-01-12 PDF 按鈕不顯示修復

## [P006] 超連結硬編碼導向錯誤
- **症狀**：點擊連結跳轉到錯誤的頁面
- **原因**：URL 硬編碼，未根據文件類型動態切換
- **解法**：使用動態函數（如 GetDocumentUrl）根據類型決定目標頁面
- **首次出現**：2026-01-09
- **出現次數**：1
- **相關任務**：2026-01-09 jID 超連結導向修復

## [P007] Hook 觸發範圍過廣
- **症狀**：終端機渲染異常、每次按鍵都觸發不必要的處理
- **原因**：Hook matcher 設定過於寬泛（如 `Bash` 而非 `Bash(git commit*)`）
- **解法**：Hook matcher 應精確限定觸發條件
- **首次出現**：2026-01-09
- **出現次數**：1
- **相關任務**：2026-01-09 Hook 終端機異常修復

## [P008] 規範無強制機制
- **症狀**：規範被忽略（如版號未更新）
- **原因**：純文字規範依賴人工記憶，容易遺漏
- **解法**：重要規範需搭配自動化檢查機制（Hook、CI/CD 等）
- **首次出現**：2026-01-08
- **出現次數**：1
- **相關任務**：2026-01-08 版號補正

## [P009] UI 控制項未對應資料庫欄位
- **症狀**：表單選擇的值存檔後再開啟會消失/變回預設值
- **原因**：UI 控制項存在，但資料庫表缺少對應欄位，或 Save/Load 邏輯未處理該欄位
- **解法**：新增 UI 控制項時，必須完成以下三步驟檢查清單：
  1. ☐ 確認資料庫表有對應欄位（無則 ALTER TABLE 新增）
  2. ☐ SaveDocument 的 INSERT/UPDATE SQL 包含該欄位
  3. ☐ LoadDocument 讀取該欄位並回填 UI 控制項
- **首次出現**：2026-01-13
- **出現次數**：2（請購人 ReqCode、採購人員 SlpCode）
- **相關任務**：2026-01-13 請購人/採購人員選擇消失修復
- **教訓**：**UI 變更必須同步考慮資料持久化**，否則用戶體驗將受損
