- **功能**：
  - 在 git commit 前自動檢查：
    1. VERSION 是否已 staged（根據 commit 類型建議版號）

  - 使用 PreToolUse hook 攔截 Bash 工具

  - 支援 feat/fix/docs/chore/refactor 等 commit 類型判斷
