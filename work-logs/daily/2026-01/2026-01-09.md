### 3. Unicode 字元轉換（減少 Claude Code Crash）
- **問題**: Claude Code 近期頻繁因中文字元導致 Rust crash
- **發現**: 配置檔中有大量 Box Drawing 字元（1,900+）
- **處理**: 轉換為 ASCII 字元
  - `┌┐└┘├┤┬┴` → `+`
  - `─` → `-`
  - `│` → `|`
  - `🔴` → `[R]`, `🔵` → `[B]`, `✅` → `[x]`, `❌` → `[ ]`
- **影響**: 17 個 markdown 檔案，特殊字元從 ~1,900 降到 0

### 5. 修復 Hook 導致終端機渲染異常
- **問題**: 在 worktree 目錄使用 Claude Code 時，每按一個鍵都會重新產生一整列新的輸入欄
- **原因**: `.claude/settings.json` 中的 PreToolUse hook 使用 `"matcher": "Bash"`
  - 導致每次 Bash 工具調用都會啟動 bash 進程執行 `version-check.sh`
  - 頻繁的進程啟動和 stdin/stdout 操作干擾終端機渲染
- **修復**: 將 matcher 從 `"Bash"` 改為 `"Bash(git commit*)"`
  - 只在 `git commit` 命令時觸發 hook
  - 一般操作（ls, git status, cat 等）不再觸發
- **影響檔案**:
  - `C:\Projects\SapB1Solution\.claude\settings.json`
  - `C:\Projects\worktrees\backend\.claude\settings.json`
  - `C:\Projects\worktrees\ui-ux\.claude\settings.json`
