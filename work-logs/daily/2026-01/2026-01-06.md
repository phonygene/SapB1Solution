### 2026-01-06-006 fix: 剪貼簿 64 位句柄截斷問題
- **問題**：`GlobalAlloc` 返回 64 位句柄 (如 0x2968A5E0008)，但未設定 `restype` 導致被截斷為 32 位
- **症狀**：`GlobalLock` 失敗 (ERROR_INVALID_HANDLE = 6)，剪貼簿永遠不可用
- **解法**：為所有 Clipboard 和 Global Memory API 設定正確的 `argtypes` 和 `restype`
- **連結**：littlebird.py:134-175
- **關鍵學習**：Windows 64 位系統上，所有返回 HANDLE/HGLOBAL 的 API 必須設定 restype

### 2026-01-06-005 fix: 剪貼簿錯誤增加詳細日誌
- **問題**：剪貼簿失敗時無法得知是哪一步驟失敗
- **解法**：在 `_set_clipboard_text` 每個失敗點增加 ERROR 日誌和 Windows 錯誤碼
- **連結**：littlebird.py:400-446

### 2026-01-06-004 fix: 通知訊息改為純英文
- **問題**：剪貼簿不可用時，typewrite 無法輸入中文，導致通知訊息被截斷
- **解法**：將 `_notify_manager_completion` 的訊息從中文改為英文
- **變更**：`[BACKEND] 任務完成，請驗收` → `[BACKEND] Task completed, please review`
